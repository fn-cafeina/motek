# Manual de usuario

Cómo se usa Motek en el día a día del taller. Las pantallas están en el orden en que las vas a usar.

## Índice

1. [Entrar al sistema](cuentas.md) — cuentas, inicio de sesión y temas claro/oscuro.
2. [Tablero](tablero.md) — el estado del taller de un vistazo.
3. [Clientes y motos](clientes.md) — registrar dueños y sus motos.
4. [Órdenes de trabajo](ordenes.md) — el corazón del sistema.
5. [Repuestos](repuestos.md) — stock, precios y ajustes.
6. [Facturas y pagos](facturas.md) — facturar una orden y cobrarla.
7. [Alertas de stock](alertas.md) — qué se está quedando sin stock.

## El recorrido típico

```
Cliente nuevo → se registra con su moto
     ↓
Se abre una orden (recibido)
     ↓
Se diagnostica y se avanza (en progreso)
     ↓
Se agregan repuestos (el stock baja solo)
     ↓
Se termina y se entrega (terminado → entregado)
     ↓
Se factura y se cobra (pendiente → parcial → pagada)
```

Los estados entre paréntesis son los que vas a ver en las etiquetas de cada pantalla. Cada capítulo explica los suyos.
