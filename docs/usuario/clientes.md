# Clientes y motos

## Registrar un cliente

En **Clientes**, botón **Nuevo cliente**. El único dato obligatorio es el nombre; el resto (teléfono, email, dirección, notas) se puede completar después desde **Editar**.

## Buscar

El buscador filtra por nombre, teléfono o email mientras escribís. El contador aclara cuántos estás viendo del total (por ejemplo "1 de 10"). Con la **✕** limpiás la búsqueda.

## Las motos de cada cliente

Cada fila tiene un botón con forma de moto que abre sus motos. Ahí se ve la lista (marca, modelo, año, placa, color, kilometraje) y se agregan nuevas con **Nueva moto**. Lo único obligatorio es la marca.

Un cliente puede tener varias motos: cada orden de trabajo se abre contra una moto puntual.

## Eliminar

Eliminar un cliente avisa antes qué se lleva puesto: sus motos y sus órdenes también se borran. Si alguna de sus órdenes ya tiene factura emitida, **no se puede eliminar**: el sistema lo explica y no ofrece confirmar, para no perder el historial de facturación. Lo mismo vale para eliminar una moto suelta.

Si necesitás dar de baja a alguien en esa situación, primero resolvé sus facturas pendientes.
